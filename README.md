# 📩 Spam Email Classifier

A Machine Learning web app that classifies emails as **Spam or Ham** using NLP and TF-IDF.

---

## 💻 GitHub Repository
👉 https://github.com/239x1a05k8-byte/Spam-Email-Classifier

## ⚙️ Tech Stack
- Python 🐍
- Streamlit 🎈
- Scikit-learn 🤖
- Pandas 📊
- NumPy 🔢
- NLP (TF-IDF Vectorizer)

---

## 🧠 Model Used
- Multinomial Naive Bayes
- TF-IDF Vectorizer

---

## 📌 Features
- Enter email text
- Predict Spam or Ham
- Real-time ML inference
- Simple UI
