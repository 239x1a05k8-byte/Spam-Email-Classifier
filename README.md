# 📩 Spam Email Classifier

A Machine Learning web app that classifies emails as **Spam or Ham** using NLP.

---

## 💻 GitHub Repository
👉 https://github.com/239x1a05k8-byte/Spam-Email-Classifier

---

## ⚙️ Tech Stack
- Python 🐍  
- Streamlit 🎈  
- Scikit-learn 🤖  
- Pandas 📊  
- NLP (TF-IDF)

---

## 🧠 Model Used
- Multinomial Naive Bayes
- TF-IDF Vectorizer

---

## 📌 Features
- Enter email text
- Predict Spam or Ham
- Simple UI
- Real-time inference
